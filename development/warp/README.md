# WARP development / Phát triển WARP

## Tiếng Việt

Mã nguồn WARP hiện nằm trực tiếp tại `net/cloudflare-warp/` và `luci/luci-app-warp/`. Thư mục này giữ tài liệu, ví dụ, kiểm thử và công cụ từ repository cũ. LuCI app có trang riêng trong Network; backend vẫn dùng netifd và WireGuard. Các bài kiểm thử cũ có thể cần chỉnh đường dẫn sau khi di chuyển.

## English

WARP source now lives directly in `net/cloudflare-warp/` and `luci/luci-app-warp/`. This folder retains documentation, examples, tests and tooling from the former standalone repository. The LuCI app has its own Network menu page; the backend still uses netifd and WireGuard. Legacy tests may require path updates.
