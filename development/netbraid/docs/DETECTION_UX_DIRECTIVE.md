# NetBraid Detection UX directive (2026-11-18)
User requirement: group detection configuration by device category/purpose, NOT by raw MAC/DHCP/TTL sensor. Main groups: Router/NAT, Is Repeater, Client/Device, Network Anomalies. Each group is a single easy toggle, with advanced settings collapsed. Is Repeater MUST use algorithmic evidence fusion with modes Auto (default), High Confidence, Sensitive. Algorithm should distinguish NAT router vs L2 bridge/repeater/WDS/mesh; use supported WiFi topology, ARP/NDP MAC/IP, DHCP, TTL/hop-limit, conntrack, TCP SYN as available; do not misclassify solely by MAC/IP multiplicity or TTL. Output type, confidence, evidence/reasons, MAC/IP, last seen. Passive monitoring only by default, no automatic blocking; allow whitelist and false-positive feedback. Ensure config schema, ucode detector, rpcd API, LuCI JS and tests are implemented consistently, with localized Vietnamese labels. This directive supplements the existing migration and safety requirements. Do not falsely claim all sensors implemented without real data collection tests.
